# Contributing

## Development Workflow

1. Create feature branch from `docs/agent-knowledgebase`
2. Make changes
3. Commit with JIRA key prefix (e.g., `FMENG-1234 description`)
4. Push and create PR

## Code Contributions

> **Note**: FMWEB repositories are primarily read-only for code changes.
> Only `.agent/` and `.md` documentation contributions are currently allowed.

## Documentation Contributions

1. Update relevant `.agent/` files
2. Keep documentation atomic with code changes
3. Use Jira keys in commit messages

## Pull Request Process

1. Ensure all checks pass
2. Request review from maintainers
3. Address feedback
4. Merge after approval

## Style Guide

- Use Yarn (not npm)
- Follow existing patterns in codebase
- Document architectural decisions
